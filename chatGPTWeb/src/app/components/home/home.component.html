Reproducibility Package Generation

You can upload either:

  • A single source file (e.g., .py, .cpp)
  • A .zip file containing a project folder

The system will automatically assign a project name based on your upload and the current date.

Dataset analysis

You can upload:

  • A scientific article in PDF format

The system analyzes the article to identify datasets and data-containing artifacts used by the authors. It checks whether these datasets are properly referenced or linked.

If a dataset is missing a reference or link, a FAIR-compliant dataset package is created with the required metadata. If a reference or link is provided, the dataset is validated for FAIR compliance and metadata completeness.
